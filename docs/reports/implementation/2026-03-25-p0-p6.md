## P0 — Fix broken things

### P0-A: JS Tooltip singleton
- Removed CSS `[data-tip]::after` tooltip block from `styles.css` (was clipped by overflow:hidden parents).
- Added JS tooltip singleton `#js-tip` in DOMContentLoaded. Handles `[data-tip]` elements and also auto-reveals truncated text on `.detail-title`, `.evidence-row__name`, `.ev-source-path`, `.review-item__label`, `.case-row__name`.

### P0-B: Exclude undated items from timeline
- `app/domain/timeline.ts`: Added `.filter((item) => isFinite(item.dateTime.getTime()))` before sort.
- `web/main.ts`: Updated `renderBriefTimeline` empty message to `'No dated items yet. Add dates to evidence to build a timeline.'`

## P6 — Smart Features + Client Goal + Export

### P6-A: Resumability
- `openCase` saves `last.caseId` and `last.screen` to sessionStorage.
- `loadHome().then()` restores last case on reload, shows resume badge.
- `showResumeBadge()` flashes a `#resume-badge` pill for 2.5s.

### P6-B: Toasts
- `showToast()` singleton added. Called on: save evidence, delete evidence, delete case, path copy, export, reprocess, topic add, goal assemble.

### P6-C: Undo navigation
- `showScreen()` now tracks previous screen and calls `showUndoNav()` when navigating away from brief.
- Undo toast shows for 4s with `↩ Undo` button to return to brief.

### P6-D: Keyboard filter navigation
- Arrow keys cycle through canvas filter panels when brief is active and focus is not in an input.

### P6-E: Truncation reveal
- JS tooltip auto-reveals full text on truncated elements (scrollWidth > clientWidth).

### P6-F: Explicit focus states
- Added `:focus-visible` rules to `styles.css`.
- Added `user-select: text` on `.ocr-preview`, `.review-ocr-preview`, `.fsd-body`, `.brief-summary`, `.goal-textarea`.

### P6-G: Range copy for OCR text
- Edit evidence modal includes Range Copy mode: click start/end sentences to copy a contiguous range to clipboard.

### P6-H: Goal builder
- "Build ↗" button in Client Goal section opens a goal builder panel with dropdowns for outcome, urgency, and an optional concern. Assembles a sentence and saves it.

### P6-I: Dynamic export
- `exportCurrentCase` now respects `EXPORT_PREF_KEY`: markdown, HTML report, or both + JSON.
- `buildHtmlReport()` generates a print-ready HTML report with timeline, key facts, gaps, evidence table, and discussion topics.
- Settings export options updated to "HTML Report" and "Both (markdown + HTML)".
